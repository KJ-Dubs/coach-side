- Connector server uses `@lovable.dev/mcp-js` here; `/mcp` and protected-resource routes are generated by the Vite plugin — keep logic in this folder. OAuth codes/tokens/clients belong to the managed Cloud OAuth server, never app tables.
- The managed server issues identity scopes only, so CoachSide permissions live in `mcp_connections`, written only by `mcp_record_consent` from a normal (non-connector) session.
- Every tool goes through `runTool` → `mcp_begin_call` (connection, permission, revoke, rate limit), then re-checks coach membership via `my_access` before RLS-scoped access; writes log via `mcp_log_action`. Why: instant revocation and team checks never trust caller-supplied ids.
